# 🎸 Мой сборник — Инструкция по установке на iPhone

## Шаг 1: Создайте аккаунт на Netlify (бесплатно)
1. Откройте https://netlify.com на компьютере
2. Нажмите "Sign up" → зарегистрируйтесь через Gmail или Email

## Шаг 2: Загрузите приложение
1. На главной странице Netlify найдите блок "Sites"
2. Перетащите папку `songbook` прямо на страницу
3. Netlify опубликует сайт за ~30 секунд
4. Вы получите адрес вида: https://ваше-имя-12345.netlify.app

## Шаг 3: Добавьте API ключ (для поиска текстов песен)
1. Зайдите на https://console.anthropic.com → создайте аккаунт
2. В разделе "API Keys" создайте новый ключ (начинается с sk-ant-...)
3. В Netlify: ваш сайт → Site settings → Environment variables
4. Нажмите "Add a variable":
   - Key:   ANTHROPIC_API_KEY
   - Value: ваш ключ sk-ant-...
5. Сохраните → Deploys → Trigger deploy

## Шаг 4: Установите на iPhone
1. Откройте Safari (обязательно Safari, не Chrome!)
2. Перейдите по адресу вашего сайта
3. Нажмите "Поделиться" → "На экран Домой"
4. Введите название → "Добавить"

✅ Готово! Работает как обычное приложение, без браузера.

## Иконки

- icon-512.png (512×512 пикселей)
